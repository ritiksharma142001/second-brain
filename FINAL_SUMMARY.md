## 🛟 **Need Help?**

### Quick Fixes:

**Script permission error:**
```bash
chmod +x setup-and-run.sh
```

**PostgreSQL not running:**
```bash
# macOS
brew services start postgresql@16

# Linux
sudo systemctl start postgresql
```

**Port 3000 in use:**
```bash
lsof -ti:3000 | xargs kill -9
```
